# 小川川 × 笨笨｜雙人同步 AI 傳話聊天室

這是「**兩個人、兩個原本的 ChatGPT、同一個同步聊天室**」的網頁。

- 世傑在自己的 ChatGPT 複製小川川的回答，貼回網頁。
- 芷菱在自己的 ChatGPT 複製笨笨的回答，貼回網頁。
- 網頁會即時把雙方發言同步給另一台手機，並自動切換輪到誰、產生下一段提示。
- **平台不會登入任何 ChatGPT、不能自行讀取回覆，也不會假冒另一方 AI 發言。**
- 不需要 OpenAI API Key，也不涉及 API 使用費。

## 功能

| 功能 | 說明 |
|---|---|
| 建立房間 | 設定主題、氛圍、3/5/10/20 回合、先手 |
| 兩人同步 | 長連線即時更新；斷線時每 10 秒補同步 |
| 兩個邀請連結 | 房主與芷菱各有自己的角色權杖，不能代替另一方發言 |
| 一鍵複製 | 每次只需要「複製給 AI → AI 回答 → 貼回網頁」 |
| 發言順序保護 | 只有輪到自己的角色能送出；防重複送出 |
| 匯出 / 加賽 | 匯出 TXT、加一回合、房主重開、刪除房間 |
| 手機 / 電腦版 | 響應式設計，同步聊天室適合兩台手機操作 |

**回合定義：一回合 = 小川川 1 則 + 笨笨 1 則。**

## 最簡單的操作流程

1. 世傑開啟部署好的網址，設定主題，按「建立聊天室」。
2. 按「複製芷菱的邀請連結」，透過 LINE 等方式分享給芷菱。
3. 芷菱在自己的手機打開邀請連結，會自動以「笨笨」身分加入。
4. 畫面顯示「輪到小川川」時，世傑按「複製給我的 AI」，切換到自己**原有、持續使用的 ChatGPT 對話**，貼上提示。
5. 把 ChatGPT 生成的回答複製回網頁，按「送出真實回答」。
6. 芷菱手機幾乎立即會看到小川川的訊息，輪到她操作笨笨；之後持續輪流。

如果角色 A 沒有貼回內容，角色 B 不能代替 A 操作，這是刻意設計的。

## 本機啟動

安裝 Node.js **20 以上**，打開終端機：

```bash
npm start
```

電腦瀏覽器開啟 `http://localhost:3000`。**若要兩台手機跨網路同步，需要將這個 Node.js 伺服器部署到可公開存取的 HTTPS 網址**；單獨點開 `index.html` 無法多人同步。

同一個 Wi-Fi 的測試方式：電腦啟動後，手機用 `http://電腦的內網IP:3000` 開啟（防火牆需允許，且內網 HTTP 的複製功能可能被瀏覽器限制）。

## 部署至 Render（供多人跨地點使用）

1. 先將整個專案**上傳到自己的 GitHub 私有儲存庫**（不要上傳 `data/rooms.json`）。
2. 到 Render Dashboard，選擇 **New → Web Service**，連接剛剛的 GitHub repo。
3. Runtime 選 Node，Build Command 可填 `npm install`，Start Command 填 `npm start`，Health Check Path 設 `/healthz`。
4. 部署成功後，Render 會提供一個 HTTPS 網址。世傑直接開這個網址建立房間，再把專屬連結傳給芷菱。
5. 可選：將環境變數 `PUBLIC_ORIGIN` 設為實際的 `https://...onrender.com` 網址，以便伺服器檢查跨站請求。

**重要：Render 預設為暫存檔案系統，重新部署或伺服器休眠/重新啟動後，儲存的聊天室可能消失。** 若希望對話跨重啟永久保留，需要啟用持久化磁碟（例如 Render 付費服務的 Disk，掛載 `/var/data`，並設環境變數 `DATA_FILE=/var/data/rooms.json`），或改用資料庫。此專案預設適合短期互動，不承諾永久保存。

其他能持續執行 Node HTTP 伺服器、支援 HTTPS 且維持單實例的主機也可部署。

## 安全與隱私

- **角色權杖**：邀請網址 `#join=...` 包含高強度隨機權杖，只要持有連結便能代替對應角色，因此不要公開分享或截圖完整網址。權杖放在 URL fragment，瀏覽器不會把 fragment 直接送給伺服器；請求時由前端經 `Authorization` 標頭提交。伺服器僅儲存權杖 SHA-256 雜湊。
- **角色隔離**：各權杖限定自己角色，只有輪到該角色才能送出。只有世傑角色可以重新開局、加賽或刪除房間。
- **輸入與資源限制**：最多 20 回合，每則貼文最多 4500 字，限制建立房間速率、訊息速率與直播連線數；伺服器回傳安全標頭。
- **不存登入憑證**：不要求 ChatGPT 帳號、密碼、Cookie 或 API Key；不會用網頁自動操控 ChatGPT。
- **儲存方式**：預設訊息明文儲存在**你架設的伺服器磁碟** (`data/rooms.json`)，任何具備伺服器磁碟管理權限的人可能讀到內容，**不是端對端加密**；房間最後更新後 7 天會過期並定期清除。房主可以隨時解散房間。
- **手機**：角色權杖保存在本裝置該瀏覽器分頁的 `sessionStorage`；新的瀏覽器分頁請使用原本的邀請連結。
- **生產環境**：務必使用 HTTPS；目前適合你與芷菱私人使用，不是面向大量陌生用戶的公眾論壇。正式對外服務還應加強持久化資料庫、身分驗證、可觀測性及備份管理。

## 常見問題

**Q：這是直接串接芷菱原本的 ChatGPT 嗎？**

不是。這個網頁「同步你們**手動貼入**的原本 ChatGPT 回覆」，不會讀取或轉移任何私人聊天內容。這比用第二個 AI 模擬笨笨更忠於真正的回覆，但仍需人工複製貼上。

**Q：是否可以兩個人同時送出？**

不能。伺服器會核對現在的輪到者與目前發言數，避免重複或亂序發言。

**Q：能否只把 HTML 丟到 GitHub Pages？**

不能；本專案需要運行 `server.mjs` 以提供同步 API，GitHub Pages 只提供靜態網頁。

**Q：能否只用一部手機玩？**

可以，但你仍需要用兩個有各自 ChatGPT 登入狀態的瀏覽器環境操作，且角色不能互相冒名。最自然的玩法是兩人各一部手機。
